Five steps from a secret on your laptop to a switch that holds even if you cannot.

  1. Create

    Write or upload the secret below. It is encrypted here; the temp copy is deleted.

  2. Send vault.json

    Give the public vault.json to each watcher you trust.

  3. Collect enrolls

    Each watcher sends back an enroll file. Paste each one into the vault card.

  4. Seal

    Split the key t-of-n. Send each watcher their own packet, and only theirs.

  5. Pulse

    Press PULSE before every deadline. Miss it, and the watchers release.
