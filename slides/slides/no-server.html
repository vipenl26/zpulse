First principles · 3

The chain is the mailbox.

Watchers never talk to each other. They never talk to a server. Each one reads Zcash with its own wallet and decides alone.

No node to seize.

No peer discovery, no consensus, no incentives to design.

A watcher that was offline catches up from the chain and misses nothing.

This is why it fit in a day. We did not build a network. Zcash already is one. A watcher is a two-hundred-line loop: sync, read memos, check the deadline, maybe send one memo.
