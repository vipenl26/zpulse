When the pulse stops

Silence past the grace period, and the world gets the key.

1

Deadline passes

Last heartbeat + interval + grace. Each watcher sees it on its own clock and the chain’s.

2

Shares go on-chain

Each watcher posts its share as a shielded memo to a public release address.

3

Anyone decrypts

The release viewing key is in the public manifest. Three memos, one key, the file.

There is no recipient. The release goes to the world, and nobody can un-publish a shielded memo.

No recipient is the big difference from z-canary. A recipient can be pressured; the world cannot. The viewing key for the release address is published, so any phone with a light wallet can collect the shares.
